Doctoral research

My doctoral research develops runtime verification techniques for programmable logic controller (PLC) program organisation units and evaluates them in controller-oriented settings. The work centres on specifications, research software, experimental evaluation of monitor behaviour and overhead, and practical integration constraints.

Results from this work appear in the Industry Track of IEEE/IFIP DSN 2025. Related project notes are below; the full citation is on the Publications page.

Academic AI · Reinforcement Learning · Published

RMLGym

RMLGym integrates Runtime Monitoring Language specifications into reinforcement learning environments, enabling explicit, property-based reward shaping. The project combines specifications, configurable monitoring and experimental RL environments, and resulted in a peer-reviewed publication.

Academic AI · Computer Vision

Detecting AI-Generated vs Real Images

Compared multiple CNN architectures for classifying authentic and AI-generated images on the 120,000-image CIFAKE dataset. The best evaluated AlexNet configuration achieved 93.4% accuracy; Grad-CAM was used to inspect model attention.

Research Software · Security Specifications

Sigma2RML

Research software that translates Sigma security detection rules into Runtime Monitoring Language specifications. Includes a parser and modular translation engine with support for temporal conditions, a FastAPI backend, a Next.js/TypeScript frontend, and tests.
