Current doctoral research

My doctoral research focuses on runtime verification and runtime monitoring for programmable logic controller (PLC) software. I design and implement monitor-generation workflows that check program organisation units against specifications during execution, then evaluate monitor behaviour, overhead and integration constraints in controller-oriented settings.

Doctoral Research · Runtime Verification · Published

Runtime Verification for PLC Systems

Developed a runtime verification approach for PLC program organisation units, including C-based specifications and a monitor-generation workflow intended to integrate with existing controller software paths.

Implemented supporting research software such as Structured Text-to-C program transformation, and ran experimental evaluations of monitor behaviour, execution overhead and practical integration constraints. Results appear in the Industry Track of IEEE/IFIP DSN-S 2025.

Runtime monitoring · PLC POUs · C specifications · experimental evaluation

Selected research projects

Peer-reviewed research that connects runtime monitoring specifications with reinforcement learning.

Published Research · Reinforcement Learning

RMLGym

RMLGym integrates Runtime Monitoring Language (RML) specifications into reinforcement learning environments so that reward signals can be shaped from explicit, monitorable properties rather than only hand-tuned scalar rewards.

The framework supports configurable monitoring and experimental RL setups for specification-guided reward shaping, and led to a peer-reviewed publication.

RML · reward shaping · Gym-style environments · experimental RL

Academic Machine-Learning Project

AI-Generated vs Authentic Image Classification

Built and compared convolutional neural network classifiers for distinguishing authentic images from AI-generated images on the CIFAKE dataset (120,000 images).

Evaluated multiple architectures, including AlexNet, VGG19 and InceptionResNetV2, under a shared experimental setup.

Research software

Tooling that supports specification translation and monitoring workflows.

Research Software

Sigma2RML

Converts Sigma security detection rules into Runtime Monitoring Language specifications through a parser and modular translation engine, including support for temporal conditions where implemented.

The system includes a Python/FastAPI backend, a Next.js/TypeScript frontend, and tests.
