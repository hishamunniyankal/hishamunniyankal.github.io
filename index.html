Featured AI & Research Work

AI Research · Reinforcement Learning · Published

RMLGym

RMLGym integrates Runtime Monitoring Language specifications into reinforcement-learning environments, enabling explicit, property-based reward shaping. The project combines formal specifications, configurable monitoring and experimental RL environments, and resulted in a peer-reviewed publication.

GitHub Publication
Academic AI · Computer Vision

Detecting AI-Generated vs Real Images

Compared multiple CNN architectures for classifying authentic and AI-generated images on the 120,000-image CIFAKE dataset. The best evaluated AlexNet configuration achieved 93.4% accuracy; Grad-CAM was used to inspect model attention.

GitHub
Doctoral Research · Formal Methods · Published

Runtime Verification for PLC Systems

Doctoral research developing runtime-verification techniques for PLC program organisation units and evaluating them in controller-oriented settings. Evidence of research methodology, research software and experimental system evaluation. Published in the Industry Track of IEEE/IFIP DSN 2025.

Publication DOI
Research Software · Security Specifications

Sigma2RML

Research software that translates Sigma security detection rules into Runtime Monitoring Language specifications. Includes a parser and modular translation engine with support for temporal conditions, a FastAPI backend, a Next.js/TypeScript frontend, and tests.
