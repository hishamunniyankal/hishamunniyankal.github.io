Profile

I am a doctoral researcher at the University of Genoa (DIBRIS), working on runtime verification and formal methods for programmable logic controller (PLC) systems. My PhD is an industrial collaboration with Technoleader SRL and COBO S.p.A., focused on making verification practical inside real controller development workflows.

Before the PhD I spent several years as a software engineer across industrial automation, big-data streaming, and full-stack web development. That background keeps my research grounded: I care about specifications and monitors that run against real systems, and about software that is measured, operable, and maintainable.

Selected work

Research and engineering projects that connect verification with practical systems.

Research

Runtime verification for PLC program organization units

Safe PLC logic needs online checks that reflect its intended behaviour. I formalised runtime verification for program organization units and evaluated it on controller-style workloads, using C as the specification language.

Published in the Industry Track of IEEE/IFIP DSN 2025 — publication details.

Research & engineering

Structured Text to C transpiler

Verification and tooling are only adopted if they fit vendor PLC workflows. I developed a Structured Text→C transpiler to improve cross-platform compatibility and performance, letting the verification framework run alongside existing controller toolchains.

Method: language transpilation, PLC toolchain integration.

Research

RMLGym

Reinforcement-learning objectives are often implicit. I developed RMLGym, a framework that integrates runtime verification with reinforcement learning to generate formal, property-based rewards that stay explicit and comparable across runs.

Published in CEUR Workshop Proceedings, Vol. 3579 — publication details.

Research & engineering

Sigma2RML transpiler

Security detection rules and formal verification frameworks usually live apart. I engineered a transpiler that converts Sigma detection rules into RML, enabling their integration with formal verification frameworks — a bridge between security analytics and runtime verification.

Method: rule translation, formal specification.
